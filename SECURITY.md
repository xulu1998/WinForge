# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | :warning: Early alpha — not yet production-ready |

WinForge is in the **Application Foundation** stage (0.1.0-alpha).
Security support will be formalized as the project matures.

## Reporting a Vulnerability

If you discover a security vulnerability in WinForge, please report it
**privately** rather than opening a public issue.

- Email the maintainers directly, or use GitHub's private vulnerability
  reporting feature once it is enabled for this repository.
- Include as much detail as possible: steps to reproduce, affected version,
  and potential impact.
- You can expect an acknowledgement within a few business days.

Please do not disclose the vulnerability publicly until a fix has been
released or a mutually agreed disclosure date is set.
