> Generated: 2026-08-10 · Branch `phase/11-component-intelligence` · ADR-045

## 1. Discovery methodology (read-only, never mutates the image)

`IComponentIntelligenceService.DiscoverAsync(workspace, ct)` runs **four** DISM
enumerations against the mounted offline working image and returns a structured
`ComponentInventory` (no raw console text is parsed by the UI):

| # | DISM command | Parser | Raw item type | Category |
|---|--------------|--------|---------------|----------|
| 1 | `dism /English /Image:<mount> /Get-ProvisionedAppxPackages` | `AppxInventoryParser` | `RawAppxPackage` | AppX |
| 2 | `dism /English /Image:<mount> /Get-Capabilities` | `CapabilityInventoryParser` | `RawCapability` | Capability |
| 3 | `dism /English /Image:<mount> /Get-Features` | `OptionalFeatureInventoryParser` | `RawOptionalFeature` | OptionalFeature |
| 4 | `dism /English /Image:<mount> /Get-Packages` | `CbsPackageInventoryParser` | `RawCbsPackage` | CbsPackage |

Six **designed-but-not-yet-implemented** categories are reported as
`InventoryStatus.NotSupported` (never silently dropped): Service, ScheduledTask,
Driver, Language, WinRecovery, SystemApp. Per-source failures are tolerated — one
failed pass does not abort the others; the failed category keeps its `Failed` status
and the rest continue.

## 2. Classification model (4-way)

`ComponentMatcher` (Core, pure, no DISM) maps each raw item onto the curated catalog
and classifies the remainder:

- **Curated** — a `ComponentDefinition`'s `TechnicalTarget` matches the raw identity
  (prefix / contains / exact). WinForge understands it: human name, short description,
  recommendation, risk, restoration, scenarios, keep-if / remove-if / impact.
- **DiscoveredUnclassified** — a Windows object exists but WinForge has no catalog
  definition for it. Shown in Advanced mode only.
- **Protected** — identity matches a system-critical marker (ServicingStack,
  Foundation, WinPE, Setup, Client-Desktop, Language*, Driver, WinRE, Recovery,
  Edition/Client/Front-page packages). Never offered for removal.
- **Unsupported** — belongs to a category WinForge does not service this stage
  (Service / ScheduledTask / Driver / Language / WinRecovery / SystemApp).

## 5. UI prototype (ordinary-user explanation)

`ComponentIntelligenceView` (Standard mode = curated only) shows, per component:
human name · short description · recommendation + risk (color-coded) · relevant
scenarios · keep-if (green) / remove-if (amber) / impact (red) · restoration info ·
estimated savings (or "Unknown") · dependencies · and a collapsed **Technical details**
Expander (raw category / identity / state / version / match rule). Any missing field
visibly renders **"Unknown" / "尚未确认"** — WinForge never invents a description or
risk.
