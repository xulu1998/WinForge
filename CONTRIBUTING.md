# Contributing to WinForge

Thank you for your interest in contributing to WinForge!

This project is in the **Application Foundation** stage (0.1.0-alpha), so the
structure is still taking shape. Contributions are welcome, but please read
the notes below first.

## Before You Start

- **Open an issue or discussion first.** Because the architecture is evolving,
  please describe your proposed change before investing significant effort.
- This repository is currently **unlicensed** (all rights reserved). By
  contributing, you agree that your contributions are provided under the
  project's eventual license terms, which are not yet finalized.

## How to Contribute

1. Fork the repository and create a feature branch from `main`.
2. Keep changes focused and small where possible.
3. Follow the existing C# / .NET coding style (`.editorconfig` will be added
   as the project matures).
4. Ensure builds succeed locally before submitting.
5. Open a pull request with a clear description of the change and its purpose.

## Commit Messages

Use clear, conventional commit messages, e.g.:

- `feat: ...` for new functionality
- `fix: ...` for bug fixes
- `chore: ...` for maintenance tasks
- `docs: ...` for documentation changes

## Code of Conduct

Be respectful and constructive. We want WinForge to be a welcoming project for
everyone who wants to build Windows their way.
